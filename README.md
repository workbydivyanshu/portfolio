# Portfolio

Source for my personal portfolio site — live at:

**https://workbydivyanshu.github.io/portfolio/**

Built from scratch with React, TypeScript, Tailwind CSS v4, and Framer Motion, deployed to GitHub Pages via GitHub Actions on every push to `main`. Self-taught full-stack developer, six real shipped projects, no filler — the site itself is the pitch, this README just points at it.

## Stack

- [Vite](https://vite.dev) + React 19 + TypeScript
- Tailwind CSS v4 (`@tailwindcss/vite`)
- Framer Motion for scroll/interaction animation
- Deployed via `.github/workflows/deploy.yml` → GitHub Pages

## Local development

```bash
npm install
npm run dev      # start dev server
npm run build    # typecheck + production build to dist/
npm run preview  # preview the production build
```
